## 🆘 AYUDA

### "No entiendo algo"
1. Lee el documento completo (no solo titulares)
2. Busca tu pregunta en TROUBLESHOOTING.md
3. Pregunta a tu equipo

### "Encontré un error en la docs"
1. Crea una rama: `docs/corregir-xxx`
2. Haz el cambio
3. Abre PR con descripción
4. Espera review

### "Falta documentación"
Crea una issue o PR con el contenido faltante.
